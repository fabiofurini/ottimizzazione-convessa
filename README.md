# Ottimizzazione convessa

Le dispense del corso di Ottimizzazione convessa in versione online: definizioni,
teoremi con le loro dimostrazioni, esempi svolti ed esercizi con le soluzioni, con
gli stessi numeri e gli stessi colori dei PDF.

**📖 Sito: [fabiofurini.github.io/ottimizzazione-convessa](https://fabiofurini.github.io/ottimizzazione-convessa/)**

## Contenuto

| Parte | Argomenti |
|---|---|
| 1 · Preliminari | insiemi convessi, funzioni di più variabili (gradiente, Hessiano, insiemi di livello), norme, funzioni convesse e concave, funzioni quadratiche |
| 2 · Problemi di ottimizzazione | problemi di ottimizzazione, ottimi locali e globali, problemi convessi e concavi |
| Esercizi | esercizi per ogni capitolo, con le soluzioni svolte |

Le dispense e gli eserciziari in PDF (due volumi ciascuno) si scaricano dalla
[pagina del materiale](https://fabiofurini.github.io/ottimizzazione-convessa/materiale/).

## Come è costruito

Le pagine, le figure e i PDF si generano in locale dai sorgenti LaTeX delle note
(privati); questo repository contiene il sito già generato (`docs/`, `mkdocs.yml`).
Per vederlo in locale:

```bash
python3 -m pip install mkdocs-material
python3 -m mkdocs serve            # anteprima su http://127.0.0.1:8000
```
